# מעקב דירות להשכרה

לוח בקרה אינטראקטיבי (`index.html`) לניהול דירות אופציונליות להשכרה.

- **נתונים:** `data/apartments.js` – Claude מוסיף כאן רשומה לכל מודעה שנשלחת אליו (קישור / טקסט / צילום מסך).
- **צילומי מסך:** `screenshots/` – גיבוי של המודעה למקרה שהפוסט יורד.
- **עדכונים מהדפדפן** (סטטוס, תאריכים, דירוג, הערות) נשמרים מקומית בדפדפן. כפתור "ייצוא" מוריד את כל הנתונים כ-JSON – אפשר לשלוח אותו ל-Claude כדי לשמור אותם בקובץ הנתונים.

פרמטרי דירוג (1–5 כוכבים, עם משקל שניתן לשנות): משופצת · מיקום · שכר דירה · ממ"ד/מקלט · גודל · מרוהטת.

## גרסה מפורסמת (משותפת)

`artifact.html` היא הגרסה שמפורסמת כדף ב-claude.ai: https://claude.ai/artifact/WpEzXSB2aW6Lv7WjEgV1zw
בגרסה הזו הנתונים נשמרים בשרת ומשותפים לכל מי שיש לו גישה לדף, וצילומי מסך מועלים ישירות מהדף.

### הוספה מקישור
יד 2 חוסם גישה משרתי ענן (Radware), ולכן המודעה נקראת בדפדפן של המשתמש:
פותחים את הדף באפליקציית Claude למחשב (Cowork), מדביקים קישור, ו-Claude בתוך הדף פותח את המודעה בדפדפן המובנה (`host:claude_browser`), מחלץ את הפרטים ושומר צילום מסך.
מחוץ לאפליקציה למחשב הקישור נשמר כ"ממתין לשליפה", ואפשר ללחוץ "שליפה עכשיו" כשפותחים את הדף באפליקציה, או להעלות צילום מסך ולמלא ממנו.
`scripts/fetch_listing.js` משמש לשליפה מהענן לאתרים שלא חוסמים.
